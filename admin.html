Importatore Articoli WordPress

Importa automaticamente tutti gli articoli pubblicati sul vecchio sito WordPress tramite le API REST integrate o caricando un file JSON / WXR.

🌐 Opzione 1: Importazione Automatica via URL WordPress

Inserisci il dominio del tuo vecchio sito WordPress. Il sistema collegherà le API REST e scaricherà articoli, copertine, autori e categorie.

📁 Opzione 2: Carica File di Esportazione WordPress (XML / JSON)

Carica il file scaricato dal vecchio WordPress (Strumenti ➔ Esporta ➔ file .xml o file .json).
