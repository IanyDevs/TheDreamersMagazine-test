Guida & Glossario degli Strumenti Redazionali

Tutto quello che c'è da sapere sui campi del pannello e come usarli al meglio.

1. Scrivi il Contenuto

Inserisci Titolo e Sottotitolo. Lo **Slug URL** si genera automaticamente. Usa la toolbar per formattare testo, tabelle e video.

2. Copertina WebP

Clicca sul box di caricamento a destra o incolla un link URL. L'immagine viene convertita in **WebP** ed espressa nell'anteprima!

3. SEO & Social Live

Imposta SEO Title e Meta Description. I simulatori in basso mostrano in tempo reale come apparirà su Google e Facebook.

4. Salva Bozza o Pubblica

Salva come **Bozza** se vuoi completarlo in un secondo momento, oppure clicca **Pubblica Subito** per renderlo subito visibile.

Glossario Strumenti: A cosa serve ogni campo

Slug URL: È l'indirizzo web univoco dell'articolo (es. /articolo/titolo-articolo). Serve ai motori di ricerca per indicizzare la pagina ed è utile per condividere un link pulito.

SEO Title: Il titolo esatto che appare nei risultati di ricerca di Google. Deve contenere le parole chiave principali dell'articolo (max 60 caratteri).

Meta Description: La breve sintesi grigia sotto il titolo nei risultati di ricerca Google. Serve a persuadere gli utenti a cliccare sul tuo link (max 160 caratteri).

Compressione WebP: Tecnologia che riduce la dimensione dei file immagine senza perdere qualità grafica, accelerando l'apertura del sito sia da cellulare che da PC.

Open Graph Title & Description: Titolo e sommario personalizzati che compaiono quando condividi l'articolo su Facebook, LinkedIn, Twitter/X o WhatsApp.

Meta Robots (index / noindex): Imposta index, follow per far trovare l'articolo su Google, oppure noindex se si tratta di una pagina privata o provvisoria.

Canonical URL: Indica a Google qual è la pagina principale originale nel caso in cui lo stesso articolo sia pubblicato su più indirizzi web.

Hero Home Page: Selezionando questa opzione, l'articolo verrà posizionato nel grande banner di copertina in prima pagina.

Importatore Articoli WordPress

Importa automaticamente tutti gli articoli pubblicati sul vecchio sito WordPress tramite le API REST integrate o caricando un file JSON / WXR.

Opzione 1: Importazione Automatica via URL WordPress

Inserisci il dominio del tuo vecchio sito WordPress. Il sistema collegherà le API REST e scaricherà articoli, copertine, autori e categorie.

Opzione 2: Carica File di Esportazione WordPress (XML / JSON)

Carica il file scaricato dal vecchio WordPress (Strumenti ➔ Esporta ➔ file .xml o file .json).
